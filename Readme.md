Gatekeeper – API Gateway

A microservices-based API Gateway project built using Spring Boot.

Services

- Smart Gateway Service – Handles incoming API requests.
- API Management Service – Manages APIs, routes, and organizations.
- Analytics Service – Tracks API usage and analytics.

Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Apache Kafka
- JWT Authentication

Project Structure

Gateway/
├── smart-gateway-service/
├── api-management-service/
└── analytics-service/

Getting Started

Clone the repository:

git clone https://github.com/Ashutosh-Mall/Gateway.git

Configure the required database and application properties, then run each Spring Boot service.
